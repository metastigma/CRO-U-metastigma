# Counter 154 — заметка для прохождения и проверки перевода

## Механика оригинала Omega 3.1.0

Противник с внутренним ID навыка `154` гарантированно контратакует в ответ на **физическое попадание**, если пережил удар.

Это не вероятность 10% / 20%. В Omega 3.1.0 RNG-вызов выполняется, но его результат не сравнивается с шансом. Поэтому Break Gauge не делает эту контратаку случайной.

Условия ответа:
- физический расчёт удара (`calc == 0`);
- после урона у носителя навыка остаётся HP;
- для текущего события ещё не назначена контратака;
- событие не является уже выполняемой контратакой.

Само умение 154 не должно вызывать ответ на магический/нефизический расчёт или после смертельного удара. Отдельная `counterStance` — другой источник контратаки.

## Проверка во время прохождения

- [ ] Найти противника с навыком ID `154`.
- [ ] Сверить в игре русское название навыка и его описание со своим переводом.
- [ ] Проверить текст навыка в анализе/информации о противнике, если этот экран доступен.
- [ ] Нанести физический удар по живому носителю: он должен ответить контратакой.
- [ ] Повторить несколько раз: контратака не должна зависеть от случайного шанса 10% / 20%.
- [ ] Проверить, что магический/нефизический и смертельный удары не вызывают контратаку по этому правилу.
- [ ] Записать противника, группу боя, место/сцену и замечания к русскому тексту.

**Статус перевода:** ожидает ручной проверки во время прохождения. Русское название и формулировку описания здесь намеренно не угадываю.
